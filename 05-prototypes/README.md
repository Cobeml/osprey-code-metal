# Interactive concept mockups

Open the HTML files in a browser. They are exported concept demonstrations with scripted inputs and outcomes. Some styling and the Fells projection library load from public CDNs, so these exports require connectivity for complete rendering.

- [Six-sector evidence replay](search-sectors.html)
- [Ground search operator view](operator-view.html)
- [Middlesex Fells trail map](fells-operator.html)
- [Boston Harbor drone-to-boat handoff](harbor-handoff.html)

The current project scenario is open ocean. The harbor and land examples are earlier interface explorations. Locations, alerts, uncertainty and trajectories shown by the overlays are simulated. They do not represent measured tracking or a calibrated drift model.

The Fells trail geometry comes from [MassGIS/DCR roads and trails](https://services.arcgis.com/sFnw0xNflSi8J0uh/ArcGIS/rest/services/DCR_roads_trails/FeatureServer). The harbor basemap comes from [Esri World Street Map](https://server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/MapServer). Basemap data retain their providers' terms and attribution.
