# Reproducible scenario inputs

Commit small synthetic fixtures with a manifest recording coordinate frame, units, timestamps, clock assumptions, ground truth, observation generation and failure schedule.

Keep original observation times separate from delivery times. Include a normal run, a communications gap, a visual gap, delayed/duplicate messages, source restart and ambiguous reacquisition.

Real recordings require provenance, applicable permissions and dataset/license information. Large recordings and model assets belong in external storage with documented retrieval and hashes. The initial fixture format will follow the accepted event contract.
